🐍 Python Interview Questions

Important Python interview questions and answers for Data Engineering roles.

Question 1
What is Python?
Answer: Python is a high-level, interpreted, general-purpose programming language known for its simple syntax and readability. It is widely used in Data Engineering, Data Science, automation and web development.
Question 2
What are the main data types in Python?
Answer: Common Python data types include int, float, string, boolean, list, tuple, set and dictionary.
Question 3
What is the difference between a list and a tuple?
Answer: A list is mutable, which means its elements can be changed after creation. A tuple is immutable, so its elements cannot be changed after creation.
Question 4
What is a dictionary in Python?
Answer: A dictionary stores data in key-value pairs. It is useful when data needs to be accessed using a unique key.
Question 5
What is a function in Python?
Answer: A function is a reusable block of code designed to perform a specific task. Functions can accept arguments and return values.
Question 6
What is OOP in Python?
Answer: OOP stands for Object-Oriented Programming. Python supports concepts such as classes, objects, inheritance, polymorphism, encapsulation and abstraction.
