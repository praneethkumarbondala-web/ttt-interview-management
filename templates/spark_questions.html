⚡ Apache Spark Interview Questions

Basic Apache Spark interview questions for Data Engineering students.

1. What is Apache Spark?

Apache Spark is an open-source distributed data processing framework used to process large amounts of data quickly. It is widely used for batch processing, streaming, analytics and machine learning.

2. What is the difference between RDD and DataFrame?

RDD is a low-level distributed collection of objects, while DataFrame is a higher-level distributed table-like structure with named columns and schema. DataFrames usually provide better optimization and easier APIs.

3. What are transformations and actions in Spark?

Transformations create a new dataset from an existing dataset, such as map(), filter() and select(). Actions trigger the actual execution of the Spark job, such as count(), collect() and save().

4. What is lazy evaluation in Spark?

Spark does not immediately execute transformations. It builds a logical execution plan and executes it only when an action is called. This is called lazy evaluation.

5. What is SparkSession?

SparkSession is the main entry point for working with DataFrames and Spark SQL in modern Spark applications. It provides access to Spark functionality from a single object.

6. What is partitioning in Spark?

Partitioning divides a large dataset into smaller parts called partitions. Spark can process these partitions in parallel across multiple executors, improving performance.
