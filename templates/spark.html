⚡ Apache Spark

Apache Spark topics that Data Engineering students should learn.

1. Spark Basics
Students should learn:
  • What is Apache Spark?
  • Why Spark is used in Data Engineering
  • Spark architecture basics
  • Driver and Executors
  • Spark Cluster basics
  • SparkSession
  • SparkContext basics
2. RDD
Students should learn:
  • What is RDD?
  • RDD characteristics
  • Creating RDDs
  • RDD transformations
  • RDD actions
  • Lazy evaluation
  • RDD persistence and caching
3. DataFrames & Spark SQL
Students should learn:
  • What is a DataFrame?
  • Creating DataFrames
  • DataFrame schema
  • Select and filter operations
  • GroupBy and aggregation
  • Joining DataFrames
  • Spark SQL
4. Transformations & Actions
Students should learn:
  • Transformations vs actions
  • map()
  • filter()
  • flatMap()
  • reduce()
  • collect()
  • count()
  • Lazy evaluation
5. Spark Performance
Students should learn:
  • Partitions
  • Repartition and coalesce
  • Shuffle
  • Broadcast variables
  • Caching and persistence
  • Data skew basics
  • Performance optimization basics
6. Spark for Data Engineering
Students should learn:
  • Reading CSV, JSON and Parquet files
  • Writing DataFrames to storage
  • ETL using Spark
  • Data cleaning using Spark
  • Handling large datasets
  • Spark with cloud storage
  • Batch processing basics
