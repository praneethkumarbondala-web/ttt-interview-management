🐍 Python

Python programming topics for Data Engineering interviews.

1. Python Basics
Students should learn:
  • Introduction to Python
  • Python installation and execution
  • Variables and naming rules
  • Python data types
  • Type casting
  • Input and output
  • Operators
  • Conditional statements
  • if, elif and else
  • for loop and while loop
  • break, continue and pass
2. Data Structures
Students should learn:
  • Lists
  • List indexing and slicing
  • List methods
  • Tuples
  • Tuple operations
  • Sets
  • Set operations
  • Dictionaries
  • Dictionary keys and values
  • Dictionary methods
  • Nested data structures
  • Mutable vs immutable objects
3. Functions
Students should learn:
  • What is a function?
  • Defining and calling functions
  • Function parameters
  • Arguments and return values
  • Positional and keyword arguments
  • Default arguments
  • *args and **kwargs
  • Local and global variables
  • Lambda functions
  • map(), filter() and reduce()
  • Recursive functions
4. Object-Oriented Programming (OOP)
Students should learn:
  • What is OOP?
  • Classes and objects
  • Constructors and __init__()
  • Instance and class variables
  • Instance methods and class methods
  • Inheritance
  • Types of inheritance
  • Polymorphism
  • Encapsulation
  • Abstraction
  • Method overriding
5. Python for Data Engineering
Students should learn:
  • File handling
  • Reading and writing text files
  • CSV file handling
  • JSON data handling
  • Working with APIs
  • Exception handling
  • Regular expressions basics
  • Python with SQL databases
  • Database connectivity
  • Data processing using Python
  • Introduction to Pandas
  • Basic ETL concepts using Python
6. Modules & Packages
Students should learn:
  • What are modules?
  • Importing modules
  • Built-in modules
  • Creating custom modules
  • What are packages?
  • Installing packages using pip
  • Virtual environments
  • requirements.txt
