🗄️ SQL Interview Questions

Basic SQL interview questions for Data Engineering students.

1. What is SQL?

SQL stands for Structured Query Language. It is used to create, read, update and delete data in relational databases. SQL is widely used by Data Engineers to query and process data.

2. What is the difference between WHERE and HAVING?

WHERE filters rows before grouping, while HAVING filters groups after GROUP BY and aggregation.

3. What is a JOIN in SQL?

A JOIN is used to combine rows from two or more tables based on a related column. Common joins include INNER JOIN, LEFT JOIN, RIGHT JOIN and FULL OUTER JOIN.

4. What is the difference between INNER JOIN and LEFT JOIN?

INNER JOIN returns only matching records from both tables. LEFT JOIN returns all records from the left table and matching records from the right table. If there is no match, NULL values are returned for the right table.

5. What is a Primary Key?

A primary key is a column or combination of columns that uniquely identifies each row in a table. It cannot contain duplicate or NULL values.

6. What is a Window Function?

A window function performs a calculation across a set of rows related to the current row without grouping the rows into a single result. Examples include ROW_NUMBER(), RANK(), DENSE_RANK(), LAG() and LEAD().
