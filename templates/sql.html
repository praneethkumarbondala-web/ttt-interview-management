🗄️ SQL

SQL topics that Data Engineering students should learn.

1. SQL Basics
Students should learn:
  • What is SQL?
  • Database and table concepts
  • Rows and columns
  • SELECT statement
  • WHERE clause
  • ORDER BY
  • DISTINCT
  • LIMIT
2. SQL Filtering & Aggregation
Students should learn:
  • AND, OR and NOT
  • IN and BETWEEN
  • LIKE
  • IS NULL
  • Aggregate functions
  • COUNT, SUM, AVG, MIN and MAX
  • GROUP BY
  • HAVING
3. SQL Joins
Students should learn:
  • What is a JOIN?
  • INNER JOIN
  • LEFT JOIN
  • RIGHT JOIN
  • FULL OUTER JOIN
  • SELF JOIN
  • CROSS JOIN
  • Joining multiple tables
4. Subqueries & CTEs
Students should learn:
  • What is a subquery?
  • Single-row subqueries
  • Multiple-row subqueries
  • Correlated subqueries
  • What is a CTE?
  • WITH clause
  • Using multiple CTEs
5. Window Functions
Students should learn:
  • What are window functions?
  • OVER()
  • PARTITION BY
  • ORDER BY inside window functions
  • ROW_NUMBER()
  • RANK()
  • DENSE_RANK()
  • LAG() and LEAD()
6. SQL for Data Engineering
Students should learn:
  • Primary keys and foreign keys
  • Constraints
  • Indexes basics
  • Normalization basics
  • Transactions
  • Views
  • Stored procedures basics
  • SQL data cleaning
  • SQL used in ETL pipelines
  • Writing efficient SQL queries
